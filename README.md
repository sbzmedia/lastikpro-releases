# LastikPro Releases

Bu repo **sadece** LastikPro masaüstü uygulamasının (macOS/Windows) mağaza dışı
otomatik güncelleme dosyalarını barındırır: derlenmiş build çıktıları
(.zip) ve bunları tanımlayan `appcast.xml` (Sparkle/WinSparkle formatı).

Kaynak kod burada YOKTUR — kaynak kod ayrı, private repolarda tutulur.

Yeni bir sürüm yayınlama adımları için `lastikpro_mobile` deposundaki
`RELEASE.md` dosyasına bakın.
